# Frontend — Marine Ops

App React (Vite + TypeScript + shadcn/ui) que consome a API Laravel em `../backend`.

```bash
npm install
cp .env.example .env   # VITE_API_URL=http://localhost:8000/api
npm run dev            # http://localhost:8080
```

Veja o [README principal](../README.md) para instalação completa, endpoints e testes.
